# 🩺 Diabetes-Prediction

### Machine Learning Project for Diabetes Prediction


## 🧠 Project Overview

This project uses Machine Learning techniques to predict whether a person is likely to have diabetes based on medical diagnostic data.

## 📁 Dataset

- **Dataset:** Pima Indians Diabetes Dataset
- **File Name:** pima-data.xlsx

## ⚙️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 📈 Seaborn
- 🤖 Scikit-learn
- 📓 Jupyter Notebook / Google Colab

## 🔄 Machine Learning Workflow

1. 📥 Data Collection
2. 🧹 Data Cleaning
3. ⚙️ Data Preprocessing
4. ✂️ Train-Test Split
5. 🤖 Model Training
6. 📊 Model Evaluation
7. 🔍 Prediction

## 📂 Project Files

- 📓 Pima_Diabetes_Prediction.ipynb
- 📊 pima-data.xlsx

## 🚀 How to Run

1. Download the project files.
2. Install the required libraries.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Upload the dataset file.
5. Run all cells.
